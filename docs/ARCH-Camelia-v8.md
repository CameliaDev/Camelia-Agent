## 2. v8 实施补丁（不影响「能否开工」）

### 2.1 右轨两层

- **上层（默认可见）系统健康：** 人闸通过率 · 残差分布 · 升闸次数  
- **下层（默认折叠）：** Router A/B 命中 · translate 拒绝率 · SkillRecord 日增  

### 2.2 探索预算

- **每日全局总封顶**（建议 50），**不**给每个 errorClass 固定 N。  
- Router 按当前 errorClass 的 UNKNOWN 频率与残差密度**按需分配**。  
- 耗尽 → 停 ε，回纯启发式，次日重置。

### 2.3 启发式版本碰撞

- 配置带 `heuristic_table_version`。  
- SkillRecord **写入该 version**。  
- 统计排序：**当前版本优先**；旧版可参考但**降权**。

### 2.4 手动降闸 = 信任窗口重置

- 连续成功计数 **清零**，须重新攒满才可再自动降闸。  
- 防「手动降闸后立刻被历史连成成功弹回去」。

### 2.5 日志：结构化摘要

- 只记元数据：errorClass、verifierId、diff 结果、闸级等。  
- **不**落完整用户代码。  
- 近 **7 天**热存，过期归档。
