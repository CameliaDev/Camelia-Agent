# Quiet shell notes

The left edge of Camelia is a 48px icon strip. Chats, Plugins, and Skills are icons on that strip. Words are tooltips.

The `quiet-activity-bar` plugin is a theme stub in the Camelia extension catalog. It records quieter ink tokens. Installing it does not replace or resize the icon strip.

Plugins load from `~/.camelia/plugins` when Camelia starts. After a catalog install, restart the app.
